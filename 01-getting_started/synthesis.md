# angular-complete-guide

## What is Angular
Angular is two things :  front-end framework + tools collection. it allows declarative code instead of imperative.
It uses TypeScript, OOP and web components. It also uses injection dependency.
Very similar to Spring: decorators, heavily opiniated, business oriented, very verbose, IOC container.

## Versions
Angular 1 = AngularJS
AngularJS != Angular "2" 
Angular 2 = Angular 16,17 ...
There is a gap before 16 and after the 16, which introduce signals.
